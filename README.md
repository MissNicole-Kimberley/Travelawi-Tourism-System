Travelawi – Web-Based Tourism Management System

Project Overview:
Travelawi is an academic project focused on simplifying tourism management by
connecting tourists, accommodation owners, and administrators through a 
centralised platform. It facilitates accommodation browsing, booking management, 
and the organisation of tourism services.

Key Features:
-Accommodation listings and browsing
-Booking management
-Favourites functionality:
-Role-based access for tourists, accommodation owners, and administrators

Technologies Used:

-HTML
-CSS
-JavaScript
-jQuery
-Bootstrap
-Node.js
-Express.js
-SQLite
-GitHub.
