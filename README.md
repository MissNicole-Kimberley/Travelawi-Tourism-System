Travelawi – Web-Based Tourism Management System

Project Overview:
Travelawi is an academic project developed for the Mobile Application Development module. It is a web-based tourism management system designed to connect tourists, accommodation owners, and administrators through a centralised platform. The system facilitates accommodation browsing, booking management, and the organisation of tourism services.

Objectives:
- To simplify tourism and accommodation management.
- To connect tourists with accommodation providers.
- To streamline accommodation booking and management.
- To support the effective administration of tourism services.

Key Features:
- Accommodation listings and browsing
- Booking management
- Favourites functionality
- Role-based access for tourists, accommodation owners, and administrators
- Accommodation management for owners

Technologies Used:
- HTML
- CSS
- JavaScript
- jQuery
- Bootstrap
- Node.js
- Express.js
- SQLite
- Git and GitHub

Project Type:
Academic Project – Mobile Application Development (MAD411)
